# CHANGELOG

One line per spec, newest first.

- **spec-05-dedupe** — The duplicate-names addendum (`docs/specs/05-duplicate-names-addendum.md`), built as item 0 of the spec 06 session: `mergeFindings` now matches on a `matchKey` that strips a leading "the", a trailing letters-only parenthetical acronym and separator punctuation, plus a second key on the full `normalizeUrl(website)` (never the host, so two dances under one parent society's site stay two rows); name key first, website key second, and a disagreement between them takes the name match and reports it on a new `MergePlan.ambiguous` rather than resolving it silently. `nameKey` is unchanged and still describes what `communities_user_name_key` enforces. Corrected at its own review gate: `normalizeUrl` in `lib/search/chain.ts` now strips a leading `www.` (the exact label only), which is what finally joins `fsgw.org/...` and `www.fsgw.org/...` as one organization and, in the search chain that shares the key, stops the loop reading one page twice. No migration, no new dependency.
- **spec-05** — Community discovery: a search-provider chain (`lib/search/`) mirroring the model gateway — Exa → Tavily → Serper, skipping any provider without a key, falling through on 429/402/auth/5xx/timeout, stopping on the first that answers including one that answers with zero results, and writing one `search_log` row per attempt; Gemini's Google Search grounding removed entirely (`ChatRequest.googleSearch`, the `google_search` tool push and the gateway flag), with `discovery_research` rewritten from returning communities to planning and critiquing rounds and a new `discovery_extraction` component turning one fetched page into organizations; a deterministic round engine (`lib/discovery/research.ts`, `round.ts`, `budget.ts`) where the empty-round rule is enforced twice — a schema minimum of 3 queries so an empty list fails the component's own output schema, and a `roundOutcome` that keeps `empty` (re-query) strictly apart from `failed` (stop and surface the provider message); robots.txt honoured with an unreachable file counting as disallowed and a disallowed page never substituted with provider-returned content; a Communities page gated on `activities_selected` advancing one round per request with resumable runs, source-URL links on every card, and editable status/focus/notes that discovery never writes; `scripts/discover.ts` running the whole loop against the real APIs and writing nothing. Migrations 0008 (enums), 0009 (`discovery_runs`, `search_log`, four discovered-fact columns on `communities`) and 0010 (`discovery_runs.pages_seen`, needed once each round became a separate request). `tsx` added as a devDependency.
